# ADN Ideas 2027

Sitio estático para recibir propuestas para las comunicaciones de ADN.

## Publicación
En GitHub, entra a **Settings → Pages**, selecciona **Deploy from a branch**, elige **main** y **/(root)**, y guarda. La web quedará publicada en:

https://cristiannldm.github.io/adn-ideas-2027/

## Archivos
- `index.html`: formulario público.
- `repositorio.html`: vista local de ideas y exportación CSV.

## Importante: almacenamiento
Esta versión inicial utiliza localStorage. Las respuestas quedan guardadas únicamente en el navegador y dispositivo donde se envían. No constituye una base de datos centralizada; para recopilar ideas de todos los participantes hay que conectar el formulario a una base de datos o servicio de formularios compartido antes de difundir el QR.
